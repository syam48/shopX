# 🛒 ShopX – E-Commerce Web App

A modern, responsive **frontend e-commerce web application** built using **HTML, CSS, and JavaScript**.
This project demonstrates core web development concepts including DOM manipulation, localStorage, filtering, and dynamic UI updates.

## 📌 Features

* 🛍 Product Listing with clean UI
* 🔍 Search functionality
* 🎯 Category-based filtering
* 💰 Price sorting (Low → High, High → Low)
* 🛒 Add to Cart system
* ➕ Remove items from cart
* 💵 Real-time total price calculation
* 💾 Data persistence using localStorage
* 🌙 Dark mode toggle
* 📱 Fully responsive design

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & layout
* **JavaScript (ES6)** – Functionality & logic
* **LocalStorage** – Data persistence
